# Newton secret-name catalog (triage #4): the ONE list consumed by both
# mcp/newton_mcp/redact.py and scripts/owrt-change.sh mask_secrets.
# One rule per line; '#' comment lines and blank lines are ignored.
# Everything is lowercase.  Fail closed: a missing, unreadable or malformed
# catalog is fatal in both consumers; there is no smaller built-in fallback.
#
#   exact <name>     the option name equals <name> (case-insensitive)
#   suffix <word>    the option name ends with _<word>
#   contains <word>  the option name contains <word>
#   allow <name>     an exact option name that is never secret (checked first)
